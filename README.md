## ⚡ Overview

**SamToolbox** is an enterprise-grade web application platform providing **84+ production-ready utility tools** across PDF manipulation, developer utilities, academic formatters, financial calculators, and regional productivity converters.

Built from the ground up on **Next.js 16 (App Router)** with **TypeScript**, every tool runs **100% client-side in the browser** using WebAssembly, Web Crypto, and HTML5 Canvas APIs with **zero server file uploads** for strict zero-trust user privacy.

---

## 🚀 Key Framework & Architectural Highlights

- **Framework:** Next.js 16.2.4 (Turbopack, Server-Side Static Generation `○ Static`)
- **Language:** TypeScript 5.0 (Strict Mode)
- **UI Engine:** React 19.2.4 + Tailwind CSS v4 + Lucide Icons
- **Rendering:** 98/98 Routes pre-rendered as Static HTML for 100/100 Core Web Vitals and instantaneous SEO discoverability.
- **Privacy Architecture:** 100% In-Browser processing via `pdf-lib`, `jspdf`, `xlsx`, `jszip`, `compressorjs`, and `WebCrypto`. Zero files ever reach a backend server.
- **Search & AI Optimization:**
  - Automated JSON-LD structured data (`WebSite`, `Organization`, `WebApplication`, `BreadcrumbList`, `FAQPage`, `HowTo`)
  - Multi-country `hreflang` alternates covering 32 locales
  - Generative Engine Optimization (GEO) & Answer Engine Optimization (AEO)
  - Full LLMO compliance with `llms.txt` and `llms-full.txt`
  - Instant Indexing via `IndexNow` protocol and Google Indexing API

## 🛠️ Local Development & Scripts

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the application.

### 3. Build for Production
```bash
npm run build
```

### 4. Search Engine Instant Indexing
Submit all 90+ routes to **Bing, Copilot & ChatGPT Search** via IndexNow:
```bash
npm run indexnow
```

Submit all routes directly to **Googlebot** via Google Indexing API:
```bash
npm run index-google
```
